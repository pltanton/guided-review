# gr v2 Implementation Plan

**Goal:** implement `docs/specs/2026-09-25-guided-review-v2-design.md`.

**Architecture:** same packages as v1. New: `internal/inbox` (viewer → agent queue).
Viewer grows layout (plan sidebar, message pane, input), split view, selection,
mouse. State gains worktree, rounds, annotations, messages, discussions.

Each task: tests first (table tests, `testrepo`, fake `glab` runner), then code, then
`go test ./... && go vet ./...`, commit.

### Task 1: Worktree and per-tree current review

- `state.Store{Dir, Key}`; current file `current-<Key>`; `Key` = first 12 hex of
  sha1(toplevel). Viewer reloads on any `current-*` change.
- `state.Review.Worktree`.
- `gitx`: `WorktreeAdd(path, sha)`, `WorktreeCheckout(path, sha)`, `WorktreeRemove(path)`.
- `gr init`: HEAD ≠ head → worktree in `UserCacheDir/guided-review/<repo>-<id>`;
  prints `code: <path>`.
- `gr done`, `gr list`.
- Tests: e2e init on other branch creates worktree at head and leaves HEAD alone;
  `done` removes it; two stores with different keys keep separate current.

### Task 2: Annotations, comment status

- `state.Annotation{File, Line, Kind, Text}`; `Step.Annotations`.
- `Comment.Resolved`, `Comment.Round`.
- `plan.Validate`: annotation file in diff, line ≥ 1, kind note|spec, text non-empty.
- `gr note add`, `gr comment resolve ID`.
- Tests: validation table rows; e2e note add appears in `gr step show`.

### Task 3: MR discussions

- `gitlab.FetchDiscussions(run, ref)` via `api --paginate`; skip system notes.
- `state.Discussion{ID, Author, Body, Replies, File, Line, Resolved}`.
- `gr init` (MR) and `gr sync` store them; `gr status` prints unresolved general
  discussions.
- Tests: fake runner JSON → parsed discussions; e2e init MR stores them.

### Task 4: Re-review rounds

- `state.Review.Round`, `PrevHeadSHA`, `RoundBaseSHA`, `RoundFiles`.
- `gr init` on existing review with new head: ancestor → `RoundBaseSHA = oldHead`;
  else `RoundBaseSHA = base`, `RoundFiles` = files whose patch text changed.
- Diff everywhere goes through `reviewRange(r)`; coverage ignores files outside
  `RoundFiles` when set.
- Output: `round 2: …`, open comments from earlier rounds.
- Tests: e2e fixup commit → round 2 diff only has the fixup hunk; rebase case →
  RoundFiles.

### Task 5: Channel

- `internal/inbox`: `Append(dir, Event)`, `ReadFrom(dir, offset) ([]Event, newOffset)`,
  offset file `inbox.offset`.
- `gr wait --timeout`, `gr say`; `state.Messages` capped at 50.
- Tests: append/read round trip; `gr wait` returns queued events and advances;
  timeout prints `no input yet`.

### Task 6: Viewer

- Rows: `OldLine`, `RowNote` rows (annotations, hotspots, comments, discussions).
- `pairRows` → split rows; `s` toggle; fallback under 120 cols.
- Layout: plan sidebar (`p`), message pane, input line (`c`/enter, `?`, `>`, `S`),
  visual selection (`v`), `n`/`N`.
- Mouse: wheel, click, drag selection, plan click → goto event, `m` toggle.
- Tests: rows with notes; pairRows; selection → event lines; key handling sends the
  right inbox events (model writes via an injected `send func(inbox.Event)`).

### Task 7: Skill and README

- Intake fast; no branch questions; `code:` path; `gr say` + `gr wait` loop with Bash
  timeout 600000; explain events → `gr note add`; re-review first step; discussions.

### Task 8: Smoke

- This repo: init on another branch (worktree), plan with annotations, viewer in a
  detached tmux session: sidebar, split, notes; send events from viewer keys, read
  them with `gr wait`.
